 Quiz Interativo para Programadores

Um projeto de site estático desenvolvido com foco em testar conhecimentos básicos de programação de forma interativa e didática.

 Sobre o Projeto:

Este projeto consiste em um quiz interativo voltado para programadores iniciantes e intermediários. Ele aborda conceitos fundamentais como:

Estruturação de páginas web
Conceitos de URL
Segurança (senhas fortes)
História do HTML
Linguagens de programação
Elementos e atributos HTML

O objetivo principal é proporcionar uma forma leve e prática de aprendizado.

Tecnologias Utilizadas:
HTML5
Tailwind CSS (via CDN)
CSS externo (style.css)

 Funcionalidades

O quiz inclui diversos tipos de perguntas, tornando a experiência mais dinâmica:

 Múltipla escolha (radio)
 Resposta em texto
 Campo de senha
 Seleção de data
 Seleção múltipla (checkbox)
 Upload de arquivo
 Menu suspenso (select)
 Identificação por imagem

Além disso:

 Tabela de pontuação com feedback
 Gabarito interativo (com <details>)
 Formulário de feedback do usuário
 Interface moderna com Tailwind CSS
 Sistema de Pontuação
Pontuação	Avaliação
0-2	Não desista! Continue aprendendo
3-4	Precisa melhorar
5-7	Bom conhecimento
8	Excelente domínio

 Como Executar
Baixe ou clone o repositório:
git clone <seu-repositorio>
Abra o arquivo index.html em qualquer navegador moderno.

Não é necessário servidor ou instalação de dependências.

 Observações
O projeto atualmente é estático, ou seja:
Não há validação automática das respostas
Não há sistema de login ou banco de dados
O botão de feedback apenas exibe um alert
